# IDENTRA — Agent Guide

## Project

IDENTRA is an independent creative studio portfolio for graphic design, AI UGC concepts, motion, and branding. This project was scaffolded from the Netlify marketing template, but the demo product catalog has been removed. There is no AI chat assistant, authentication, ecommerce, or custom database in the current implementation.

## Architecture

- React 19, TypeScript in strict mode, TanStack Start, and TanStack Router.
- Vite 7 with the Netlify TanStack Start plugin; deployment settings live in netlify.toml.
- Tailwind CSS 4 is available, with the primary visual design expressed through custom CSS and shared tokens.
- Netlify Forms persists project inquiries. React state is used only for transient UI interactions.

## Key directories

- src/routes/index.tsx: home page, responsive navigation, filters, project rail, project preview dialog, process accordions, and inquiry form.
- src/routes/__root.tsx: document shell, metadata, external font links, favicon, branded not-found and error pages.
- src/data/projects.ts: static portfolio concepts, category labels, typed project records, and proposed deliverables.
- src/components/Artwork.tsx: original code-native CSS/SVG artwork, shared between hero, cards, gallery, and dialog.
- src/styles.css: design tokens, layouts, responsive breakpoints, artwork styling, and animations.
- src/router.tsx: router setup and scroll restoration. The route tree is generated by the framework; do not edit it manually.
- public/__forms.html: static Netlify Forms registration skeleton. This is essential even though the public interface is rendered by React.
- public/favicon.svg: IDENTRA’s coral studio mark.
- docs/assets/identra-prototype.html: supplied source prototype retained as an archival design reference, not a production page.
- .netlify/results.md: standalone summary of completed changes.

## Conventions

Use PascalCase component names, camelCase functions and variables, descriptive identifiers, and explicit TypeScript interfaces. Use type-only imports where appropriate and the @/ alias for src imports. Keep styling consistent with the established dark palette, Anton display headings, Manrope body type, and JetBrains Mono labels. Prefer shared CSS variables over duplicate color values.

Use semantic HTML, accessible labels, keyboard interaction, and visible focus states. The project preview uses a native dialog, restores focus on close, and supports Escape and backdrop dismissal. Preserve reduced-motion behavior, including programmatic carousel scrolling. Decorative artwork is hidden from screen readers; project buttons retain readable titles.

All current work is conceptual. Do not imply that these are client campaigns, real AI avatar videos, or completed commercial deliverables. Animated previews are CSS visual studies with no audio. Real media should only be added when supplied or approved. Do not publish invented social handles, contact addresses, testimonials, performance claims, or client relationships.

## Form integration

The form name is project-inquiry. React and public/__forms.html must use identical field names: form-name, bot-field, name, email, company, service, budget, and message. Submit as application/x-www-form-urlencoded to /__forms.html, not /, because the SSR catch-all would otherwise intercept submission. Keep the honeypot, native validation, duplicate-submit prevention, timeout, success feedback, and preserved-input error handling.

Netlify Forms is enabled via /opt/buildhome/.agents/skills/netlify-forms/scripts/enable.cjs. Run the relevant platform activation script if reimplementing or changing the feature. Email notifications are configured in Netlify, not hardcoded in the app.

If future features need queryable application data, read the general-database and netlify-database skills and use Netlify Database with Drizzle. Do not add local JSON storage, browser storage, or an external database for persistent application records.

## Development and validation

Use Node.js 22 and pnpm. Install with pnpm install; local Netlify development uses netlify dev --port 8889. The basic pnpm dev command starts Vite on port 3000 without full Netlify emulation. The configured deployment pipeline installs dependencies and runs the production build.

During agent-runner Build mode sessions, do not execute local build, typecheck, test, or dev-server commands when session instructions prohibit them. Inspect changes by reading source; leave runtime validation to the automated pipeline. Do not add a test or formatter toolchain unless requested. Do not inspect the .git directory, create commits, or print secrets.
